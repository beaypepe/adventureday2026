# 🌍 Adventure Day 2026 — BeayPepe

Aplicación web interactiva diseñada para el evento especial **Adventure Day 2026**, organizado por el equipo **BeayPepe** el **29 de noviembre de 2026**.

🔗 **Acceso a la aplicación:** [https://beaypepe.github.io/adventureday2026/](https://beaypepe.github.io/adventureday2026/)  
🐙 **Repositorio:** [https://github.com/beaypepe/adventureday2026](https://github.com/beaypepe/adventureday2026)

---

## 🎯 ¿En qué consiste?

Durante el evento presencial, los asistentes encontrarán múltiples códigos QR físicos sobre la mesa. 
* Solo **5 códigos QR** conducen a los retos interactivos correspondientes a las 5 etapas del **Adventure Lab** del evento.
* El resto de los códigos QR son señuelos que llevarán a una página sin salida.
* Al superar cada minijuego desde el teléfono móvil, el jugador obtendrá la clave necesaria para validar la etapa correspondiente en la app oficial de **Geocaching Adventure Lab**.

## 📱 Requisitos de uso

* **Dispositivo:** Optimizado exclusivamente para **smartphones** (pantallas táctiles en orientación vertical).
* **Navegador:** Cualquier navegador móvil moderno (Chrome, Safari, Firefox, Brave) con JavaScript activado.
